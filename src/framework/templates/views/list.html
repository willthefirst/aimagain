{# Generic list-view chrome. A list view (`/posts`, `/providers`, `/users`, `/users/me/favorites`, `/users/{id}/providers`) renders the same chrome: primary nav (from `base.html`), single-segment breadcrumb naming the resource, then a single toolbar strip (search link + Clear all on the left, action menu on the right). The search link summarizes any active filters inline — there is no separate active-filter strip. Child contract: Required blocks: resource_label — short string label for the breadcrumb segment (e.g. "Providers"). Plain text, no markup. content — the table or list body (typically an `index_table(...)` call or a hand-rolled `
    `). Optional blocks: actions — toolbar right-zone content (Create button, Export link). Each action is a `
  • ` because the right zone is a `` (commands list). Empty by default. breadcrumb — full breadcrumb override for subresource lists with multi-segment chains.
