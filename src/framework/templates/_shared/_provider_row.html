{# Shared provider-row macros — used by every list of providers. Lives in `_shared/` rather than `providers/` because four templates across three clusters render the same row (`/providers`, `/users/me/favorites`, `/users/{id}/providers`, and the embedded "Providers" section on the user detail page). Cross-cluster template imports aren't allowed (see ../README.md "Layering rule"), so the shared shape goes here. Filters for the `/providers` index are declared on `PROVIDER_ENTITY.filters` and render on the dedicated `/providers/search` page (via `views/search.html`) — there's no provider-specific filter partial to maintain. The Insurance cell composes the same posture summary used on the provider detail card (#449): "In-net" / "Out-net" / "Self-pay", with optional "· sliding" when sliding scale is on.
