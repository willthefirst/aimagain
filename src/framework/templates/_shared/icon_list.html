{# Bulleted-with-Lucide-glyphs list. The default `
    ` disc bullet plus a leading Lucide icon double-marks every item (the screenshot in #647-followup showed this). This macro emits a `
      ` whose list-style is stripped via `base.html`, letting the Lucide glyph serve as the only marker. Class is `glyph-list` (not `icon-list`) because Lucide ships an `icon-list` glyph whose `::before` font-character would render on the `
        ` itself if we used the same class name — collision with the icon-font namespace, not with our intent. Items are plain `{"icon": "pill", "label": "Medication management"}` dicts — pass whatever sequence of mappings the caller has, in display order. Lucide icon class names live in [`src/framework/static/icons/`](../../static/icons); the `[class^="icon-"]` rule in `base.html` gives every glyph its trailing `margin-inline-end: 0.25em` gap, so this macro adds no per-item spacing CSS. When a per-item label needs richer content than plain text (a link, strong emphasis), inline the `
      • ` directly instead of passing through the macro — three lines of HTML stays cheaper than overloading the contract.
