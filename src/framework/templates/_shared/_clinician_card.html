Headline: the clinician's "{first_name} {last_name}" when both are set; falls back to whichever is set, or to "Unnamed clinician" when neither is. Body — each fact reflects every affiliation the clinician holds: - Practice (linked Org chips, one per affiliation). - Location ("City, ST" chips, deduped on identical strings). - Licensed in (issuing-state code list). - Insurance (rendered via `clinician_card_view`). Redaction — when the viewer lacks provider-network access AND isn't the clinician's owner, the identifying rows (name, practice, location) render `locked_name`/`locked_field` placeholders instead of the real values. Mirrors the `posts/_shared/_facts_block.html` `redacted=` pattern.
