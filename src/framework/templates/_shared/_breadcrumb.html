Each item is a `(label, href, lock_reason?)` tuple. Per item: - `lock_reason` set (a closed-vocab `REASON_*` code, see `_locked.html`) → a `data-locked-cta` popover trigger with no `href`, so the visible link can't disagree with the destination's `read_policy.assert_can_read`.
