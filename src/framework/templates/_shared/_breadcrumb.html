{# Breadcrumb zone bar primitive. Renders the page's location as a single "back" affordance — a Lucide arrow-left chevron plus the deepest clickable parent's label. Sits in the `breadcrumb` block slot wired in [`../base.html`](../base.html). No band chrome (background, border, padding); just inline text with an icon. Each item is a `(label, href, lock_reason)` tuple — the third element is optional and defaults to `None`. The last item's `href` is typically `None` (the current page); the back target is the deepest item with a non-None `href` — for two-level chains (collection → current) that's the collection link, for nested chains (collection → row → edit) that's the row link. When `lock_reason` is set on the back target (a closed-vocab `REASON_*` code — see `_locked.html`), the back affordance renders as `locked_link(reason, label)` instead of an ``, so the visible link can't disagree with the destination page's `read_policy.assert_can_read`. Mount helpers compute the reason via `entity_lock_reason(name, user)`; per-template callers (the detail-view collection breadcrumb) use the Jinja-global form.
