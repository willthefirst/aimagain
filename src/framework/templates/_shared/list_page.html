{# Toolbar helper for the canonical list page. List pages extend `_shared/_list_page.html` (which auto-fills the breadcrumb from the `resource_label` block); this file just supplies the optional toolbar shell that wraps the filter widget on the left and accepts a `{% call %}` body for the right-zone action cluster: {% block toolbar %} {% call list_toolbar(filters=filters, action="/posts", values={...}) %} Create post {% endcall %} {% endblock %} When a page has neither a filter widget nor a right-zone action it omits the toolbar block entirely — `list_toolbar` is opt-in. #} {%- from "_shared/index_filters.html" import index_filters -%} {# List-page toolbar shell. Renders the filter widget in the left zone when `filters` is provided; renders the `{% call %}` body in the right zone when invoked with one. When neither is present the macro emits nothing — pages without page-scoped controls can wrap the call in `{% if filters %}` or just omit the toolbar block. Args: filters: optional `Filter` tuple from `EntitySpec.filters` (the same shape `index_filters` reads). action: the list URL the filter form GETs to. values: dict of `{filter.name: current_value}`; passed straight through to `index_filters`.
