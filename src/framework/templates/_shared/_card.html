{%- endmacro %} {% from "_shared/sections.html" import fact, facts_block, meta_sep %} {# Subresource card — declarative wrapper around `card` for the clinician credential lists (certifications, licensures, educations) and any future subresource that follows the headline + subtitle + short fact-list shape. Caller provides: - `id`, `headline_url`, `headline` — same as `card`. - `subtitle_parts` — iterable of strings. Falsy entries are skipped; the rest wrap in ``, joined by `meta_sep()` so the `.meta` line reads "Active · CA". Pass `["Active", lic.issuing_state]`. - `facts` — iterable of `(key, label, value)` triples. Triples whose `value` is falsy are skipped. Rendered inside a single `facts_block`; an all-empty list emits no block at all.
