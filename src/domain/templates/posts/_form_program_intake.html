{# Shared form body for `kind='program_intake'` (#541). Used by both `posts/new_program_intake.html` (create) and `posts/edit_program_intake.html` (update). After #1358 PR-f sub-3 the announcement is **thin by design**: only program picker + availability + announcement-specific free text. The steady-state profile (services / settings / modalities / age_groups / languages / genders / website / referral_instructions) is managed on the linked Program — see `src/domain/models/programs/README.md`. Field order: 1. Which program — establishes context for the whole form (followed by a read-only preview of that program's profile) 2. About — description (free-text announcement copy) 3.
