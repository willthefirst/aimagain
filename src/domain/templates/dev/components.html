Foundations

The UI is built on Pico.css — a classless semantic CSS framework. Typography, color tokens, form elements, buttons, and spacing all come from Pico. Refer to the Pico docs for the full token reference and component catalog.

Icons are from Lucide, served as a self-hosted icon font. Only the icons referenced in templates and enums are bundled — see src/framework/static/fonts/lucide-icons.css for the allowlist and the per-icon "how to add one" instructions. Use a bundled icon with <i class="icon-{name}"></i> where {name} is the Lucide icon name in kebab-case; browse the full Lucide set at lucide.dev/icons.

    Locked affordances

    Four variants for "you can't do/see this yet" UI. Each carries a data-locked-cta="{reason}" attribute. Clicking opens a native <popover> CTA card anchored via CSS anchor positioning (position-try-fallbacks keeps it on-screen near the trigger). Copy and fix-URL come from capabilities.reason_meta(reason).

    {# locked_action — disabled-looking button (write affordances) #}

    locked_action

    Rendered in place of a create/submit button the user doesn't have access to. Looks disabled; clicking opens the CTA popover.

    Default {{ locked_action(capabilities.REASON_NOT_A_VERIFIED_PROVIDER, "+ Post a referral") }}
    extra_class="secondary" {{ locked_action(capabilities.REASON_NOT_A_VERIFIED_PROVIDER, "Email", extra_class="secondary") }}
    email reason {{ locked_action(capabilities.REASON_EMAIL_UNVERIFIED, "Submit") }}
    {# locked_link — disabled-looking inline navigation link #}

    locked_link

    Rendered in place of an <a> the user can't navigate to yet. Muted, not-allowed cursor, opens CTA popover.

    {{ locked_link(capabilities.REASON_NOT_A_VERIFIED_PROVIDER, "View full profile") }}
    {{ locked_link(capabilities.REASON_EMAIL_UNVERIFIED, "Continue") }}
    {# locked_name — withheld identity placeholder #}

    locked_name

    Rendered where a clinician or org name would appear. The placeholder communicates "a real name exists here." Always uses REASON_NOT_A_VERIFIED_PROVIDER.

    clinician {{ locked_name("Dr. J. Doe") }}
    org / program {{ locked_name("Doe Health Group") }}
    {# locked_field — withheld data value (address, contact) #}

    locked_field

    Rendered where a withheld data value (full address, phone) would appear. The redacted dots signal content exists; the lock icon signals it's gated.

    network_unverified {{ locked_field(capabilities.REASON_NOT_A_VERIFIED_PROVIDER) }}
    email_unverified {{ locked_field(capabilities.REASON_EMAIL_UNVERIFIED) }}
