{# Shared breadcrumb trail. Caller passes a list of `(label, url)` tuples; the last entry's url is ignored (the current page is rendered as plain text rather than a link). Used by detail pages and nested-list pages to surface their position in the hierarchy. Top-level list pages (`/posts`, `/users`, `/providers`, `/users/me/favorites`) don't render a breadcrumb — their title is the breadcrumb. Usage (in a per-page template): {% from "_shared/_breadcrumb.html" import breadcrumb %} {% block breadcrumb %} {{ breadcrumb([ ("Posts", "/posts"), (post.title_or_kind_label, None), ]) }} {% endblock %} The macro renders inside the page's `{% block breadcrumb %}` slot in `base.html` — placed above `
` so it's visually adjacent to the primary nav but distinct from the page title. #} {% macro breadcrumb(items) -%} {%- if items -%}
    {%- for label, url in items -%}
  1. {%- if not loop.last and url -%} {{ label }} {%- else -%} {{ label }} {%- endif -%}
    2. {%- endfor -%}
{%- endif %} {%- endmacro %}
